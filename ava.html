Connect your WhatsApp account

Follow these steps in Meta for Developers, then send us your credentials below so we can finish connecting your bot.

If you face any issues during the setup process, please contact our support team immediately, and we will solve it for you.

Security Note: These settings are 100% safe. Their sole purpose is to grant our platform access to manage your WhatsApp account exclusively for sending and receiving messages.

Step 1: Add Real Phone Number

(Skip this step if you are only testing with the provided Meta test number)

  1. Go to your app dashboard in Meta for Developers.
  2. From the side menu, select WhatsApp > API Setup.
  3. Scroll down to Step 5: Add a phone number, and click Add Phone Number.
  4. Enter your business display name, then enter the phone number you want to use for WhatsApp Business.
  5. Choose your verification method — Text Message (SMS) or Voice Call — then enter the OTP verification code.
  6. Once verified, copy the new Phone Number ID generated for your official number.

Step 2: Generate Permanent Access Token

  1. Open Meta Business Settings: business.facebook.com/settings.
  2. From the side menu, go to Users > System Users.
  3. Click Add: enter a system username (e.g., Bot-Admin), and set the user role to Admin.
  4. Click Assign Assets on the same page: select Apps, choose your WhatsApp application, enable Full Control / Manage App, then click Save Changes.
  5. Click Generate New Token: select your app, set token expiration to Never, and check (✔) only whatsapp_business_messaging and whatsapp_business_management.
  6. Click Generate Token, copy the Access Token immediately, and save it securely.

Required credentials to submit: Phone Number ID, Permanent Access Token.

Important: please do not modify these settings or delete the created System User or Access Token in the future, to avoid any service disruption or disconnection.

ملاحظة أمان: هذه الإعدادات آمنة تماماً، والهدف منها فقط هو منح منصتنا الصلاحية لإدارة حسابك على واتساب لإرسال واستقبال الرسائل نيابة عنك.

الخطوة 1: إضافة رقم الهاتف الفعلي

(تُنفذ فقط إذا كنت ترغب باستخدام رقمك الفعلي بدلاً من الرقم التجريبي)

  1. اذهب إلى لوحة تحكم التطبيق في Meta for Developers.
  2. من القائمة الجانبية اختر واتساب (WhatsApp) > إعدادات API (API Setup).
  3. انزل حتى الخطوة 5: إضافة رقم هاتف (Add a phone number)، واضغط زر إضافة رقم هاتف (Add Phone Number).
  4. أدخل اسم منشأتك، ثم رقم الهاتف المخصص لواتساب الأعمال.
  5. اختر طريقة التفعيل: رسالة نصية (SMS) أو مكالمة صوتية (Voice Call)، ثم أدخل رمز التأكيد.
  6. بعد اكتمال التفعيل، انسخ معرّف رقم الهاتف (Phone Number ID) الجديد الخاص برقمك.

الخطوة 2: استخراج رمز الوصول الدائم (Permanent Access Token)

  1. افتح رابط إعدادات الأعمال: business.facebook.com/settings
  2. من القائمة الجانبية اذهب إلى المستخدمون (Users) > مستخدمو النظام (System Users).
  3. اضغط زر إضافة (Add): اكتب اسم مستخدم (مثلاً: Bot-Admin)، واختر دور المستخدم: مسؤول (Admin).
  4. اضغط زر تعيين الأصول (Assign Assets) بنفس الصفحة: حدد التطبيقات (Apps)، اختر تطبيقك، فعّل التحكم الكامل (Full Control / Manage App)، ثم احفظ التغييرات.
  5. اضغط توليد توكن جديد (Generate New Token): اختر تطبيقك، مدة الانتهاء: مطلقاً (Never)، وفعّل فقط علامة (✔) أمام: whatsapp_business_messaging وwhatsapp_business_management.
  6. اضغط توليد التوكن (Generate Token)، وانسخ رمز الوصول (Access Token) الظاهر فورًا واحفظه بمكان آمن.

البيانات المطلوب إدخالها بالموقع: معرّف رقم الهاتف (Phone Number ID)، رمز الوصول الدائم (Permanent Access Token).

تنبيه هام: يرجى عدم تغيير هذه الإعدادات أو حذف حساب مستخدم النظام (System User) الذي أنشأته لاحقاً، تجنباً لانقطاع الخدمة وتوقف الربط.
